# 人物出镜审核工作流

具体操作、默认素材与快捷键见[使用与演示手册](system_user_guide.md)，部署及数据维护见[部署维护手册](system_operations.md)。

## 用户与任务

审核员的主要任务是处理系统整理出的疑似人物出镜片段，记录判断，并交付范围明确的审核记录。系统减少浏览整片和寻找上下文的工作，最终身份判断由审核员完成。

## 工作空间

- 工作台：待复核任务、检查中的任务、待处理线索、已完成审核。
- 审核任务：按名称或状态定位任务，开始检查、继续复核或查看记录。
- 待我复核：集中显示仍需人工处理的任务；当前为单机工作空间，并非多人分派。
- 审核记录：查看已完成任务；未完成任务也可从详情导出带状态说明的记录。
- 人物库：管理姓名、分类、别名、审核说明、参考照片；支持新建、编辑、导入本地照片。
- 词语及内容库：管理审核范围，当前不参与自动检查。
- 维护工具：技术验证入口，不属于审核员的主要操作流程。

## 主要流程

1. 选择本地视频，勾选核查人物，填写任务名称并提交。
2. 系统检查；显示进度，用户可离开页面处理其他任务。
3. 进入片段复核；默认打开未处理条目，对照画面与人物参考照片，按需播放上下文。
4. 选择确认出现、排除或留待复核；可附备注。结果持久保存，并打开下一条未处理条目。
5. 所有条目解决后完成审核；导出任务范围、处理结果、位置与备注。

## 信息原则

审核页只显示帮助用户判断和操作的信息。模型相似度、采样间隔、特征向量、算法版本与原始路径不作为常规审核信息。播放位置由播放器承担，后台保留精确定位信息用于证据追溯。

人物提示是待核查对象，不代表已经识别为本人。历史抽检任务明确其只包含部分画面；无候选不等于影片全部审核通过。范围不足、未解决疑点和已知读取失败必须影响任务完成条件。

## 当前边界

这是本地可操作工作空间。多人账号、角色权限、任务分派、外部部署与团队数据库需要后续实现。算法仍需独立标注与跨媒资验证；产品界面不展示未经验证的准确率。
